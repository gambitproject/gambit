.. _code-of-conduct:

Code of Conduct
---------------

Gambit is committed to a welcoming, harassment-free community for everyone, regardless of
background or identity.  Be kind, respectful and considerate, and resolve disagreements constructively.

To raise any concerns, please contact `Ted Turocy <mailto:ted.turocy@gmail.com>` or `Rahul Savani
<mailto:rahul.savani@gmail.com>`.

.. _github-issues:

GitHub issues and discussions
-----------------------------

Report bugs in the `Gambit issue tracker
<https://github.com/gambitproject/gambit/issues>`_, using the issue template.

Include:

* the Gambit version, and whether the bug occurs in both the stable and development versions;
* the operating system; and
* steps to reproduce the bug, with a minimal game file where relevant.

Propose features and improvements on the `Gambit discussions boards
<https://github.com/gambitproject/gambit/discussions>`_.  Keep posts relevant to feature
development; off-topic posts may be removed.


Recognising contributions
-------------------------

Gambit uses `All Contributors <https://allcontributors.org/>`__ to recognise code,
documentation, bug reports, and other contributions.  The contributor list appears in the
`repository README <https://github.com/gambitproject/gambit>`__.
