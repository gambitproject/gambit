.. _developer:


Developer docs
==============

This section contains information for developers who want to contribute to the Gambit project, including how to build Gambit from source, how to contribute code, and how to report bugs.
For instructions on contributing new games to the catalog, see the `catalog's own developer guide <https://gambit-catalog.readthedocs.io/en/latest/developer.html>`_ (built and versioned separately from these docs).
