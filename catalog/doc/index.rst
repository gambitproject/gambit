Catalog of games
================

Below is a complete list of games included in Gambit's catalog.
See the main `pygambit documentation <https://gambitproject.readthedocs.io/>`_ for the
the `pygambit.catalog API reference <https://gambitproject.readthedocs.io/en/latest/pygambit.api.html#pygambit-catalog>`_
(including how to load these games in Python),
for loading games from the OpenSpiel library, and for generating games on the fly
from the GAMUT suite.
See :ref:`Updating the games catalog <updating-catalog>` below for instructions on how
to contribute new games to the catalog.
